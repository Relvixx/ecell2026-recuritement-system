# 1. Technical

Tagline:
**The Builders**

Card:
**Build the digital systems, tools and tech behind E-CELL.**

Description:
The Technical team works on the technology that keeps E-CELL moving—from websites and registration systems to automation, event tech and internal tools.

Fit:
You may fit here if you enjoy building things, solving problems, experimenting with technology or figuring out why something isn't working.

Responsibilities / work areas:
- Websites
- Registration systems
- Automation
- Internal tools
- Event technology
- Technical troubleshooting
- New experiments

Visual motif:
- nodes
- grid
- terminal fragments
- connection diagrams

Pastel identity:
Powder Blue

Application questions:

### What technologies or tools have you tried?
Options:
- HTML / CSS
- JavaScript
- React / Next.js
- Python
- Git / GitHub
- Databases
- Arduino / Hardware
- AI tools
- Other
- I'm just getting started

### Tell us about something technical you've tried or built—even if it didn't fully work.
Helper:
We're interested in how you explore and solve problems, not just finished projects.

### Project / GitHub / portfolio link
Optional.

# UI/UX Master Specification

## 1. Design Identity

### Soft Editorial Playground

The platform should feel like:

**Independent Creative Studio × Editorial Magazine × Curated Campus Scrapbook**

Participant reaction target:

> “Wait… this is a college club recruitment page?”

followed by:

> “And it actually feels professional.”

---

## 2. Personality

The interface must feel:

- Soft
- Playful
- Editorial
- Creative
- Youthful
- Premium
- Human
- Confident

Golden rule:

> Playful, not childish.  
> Unique, not weird.  
> Premium, not corporate.  
> Soft, not washed-out.

---

## 3. Visual Energy

Use:
- calm neutral base
- expressive typography
- restrained pastel surfaces
- real photography
- tiny human details
- controlled asymmetry
- generous whitespace

Avoid visual noise.

Do not create attention through:
- neon
- glow
- huge gradients
- constant motion
- excessive shadows
- heavy bold type

---

## 4. Color World

### Base Canvas
Warm ivory / milk / soft cream.

Suggested direction:
- `#FAF8F3`
- `#FCFAF6`
- `#FFFDF9`

### Main Text
Deep charcoal / warm ink.

Suggested direction:
- around `#282626`

Do not use pure black everywhere.

### Pastel Family
Use a family of restrained accents:
- Lavender
- Powder Blue
- Sage
- Butter Yellow
- Blush
- Peach
- Soft Mint

Example working values:
- Lavender `#DDD6F3`
- Powder Blue `#D7E7F3`
- Sage `#DCE8D4`
- Butter `#F5E7AD`
- Blush `#F2D7DD`
- Peach `#F1D8C7`
- Mint `#D8ECE2`

Exact HEX values can be tuned later. The behavior is locked.

### Recommended Visual Ratio
- ~65% warm neutral
- ~25% pastel surfaces
- ~10% photography / graphics / deep text

Do not turn each page section into a different rainbow panel.

---

## 5. Team Color Identity

Suggested team associations:

- Technical → Powder Blue
- Design → Lavender
- Documentation → Peach / Warm Cream
- Social Media → Blush
- PR → Soft Coral / Peach
- Event → Butter Yellow
- Research → Sage / Mint

These are accents, not mandatory full-card fills everywhere.

---

## 6. Shape Language

Use:
- soft rounded rectangles
- irregular/asymmetric card geometry
- pills for small tags
- pastel paper-like surfaces
- occasional circles/ovals
- custom image framing

Do not apply the same radius to every component.

Approx direction:
- large editorial card: 28–36px
- button: soft pill / 18–24px
- input: 14–18px
- image: context-specific frame

Avoid the “everything is rounded-3xl” AI look.

---

## 7. Photography

When real assets arrive, photography should become a hero visual element.

Prefer:
- candid team moments
- event preparation
- backstage activity
- real work
- stage/audience energy
- natural expressions
- collaboration
- execution

Avoid relying mainly on:
- formal posed group photos
- certificate photos
- generic stock imagery

Temporary placeholder media should mimic the same composition types.

---

## 8. Scrapbook Language

Use a **curated editorial scrapbook**, not random Pinterest chaos.

Allowed in moderation:
- paper tape
- handwritten arrow
- scribble
- small stamp
- underlines
- slight image overlap
- one or two rotated photos
- tiny handwritten annotation

Every viewport must still have a clear focal hierarchy.

---

## 9. Illustration System

If doodles/illustrations are used, they must look like one coherent set.

Potential motifs:
- arrow
- star/spark
- light bulb
- paperclip
- camera
- megaphone
- folder
- laptop
- ticket
- magnifier
- speech bubble
- sticky note

Avoid mixing random:
- emoji
- 3D icons
- inconsistent doodles
- unrelated illustration styles

---

## 10. Layout Philosophy

Avoid generic AI landing-page repetition:

BAD:
- centered heading
- centered paragraph
- centered button
- 3 equal cards
- repeat

GOOD:
- asymmetric hero
- text + visual editorial section
- full-width scrapbook media moment
- structured but irregular team grid
- staggered benefit cards
- clean timeline
- minimal FAQ
- quiet final CTA

The visual rhythm should change from section to section.

---

## 11. Whitespace

Whitespace is a core design element because hierarchy should not rely on heavy typography.

Desktop:
- generous vertical breathing room
- major section gaps roughly 120–176px

Mobile:
- tighter but still breathable
- typical major section gaps ~72–96px

Do not cram content just because screen space is available.

---

## 12. Landing vs Form vs Admin

### Landing
Most expressive:
- editorial composition
- photography
- scrapbook accents
- pastel paper layers
- custom typography

### Application
Calmer:
- warm neutral base
- focused form layout
- minimal decoration
- pastel selection states
- clear progress

### Admin
Most functional:
- structured
- quiet
- compact
- light pastel status system
- almost no scrapbook decoration

Same brand, different intensity.

---

## 13. Human-vs-AI Design Rule

AI-made websites often over-optimize symmetry.

Introduce controlled human decisions:
- one slightly rotated image
- unusual line break
- handwritten annotation
- asymmetrical spacing
- one card that intentionally breaks the grid
- deliberate empty space

Do not make everything perfectly equal.

---

## 14. Anti-Patterns — Explicitly Forbidden

Unless Rahul later unlocks them:

- dark theme
- neon/electric palette
- cyberpunk
- huge heavy bold headings
- Inter/Poppins-everywhere aesthetic
- purple gradient hero
- excessive glassmorphism
- glowing cards
- random emoji UI
- excessive drop shadows
- stock-photo-heavy design
- giant animated gradient blobs
- 3D tech illustrations
- scroll hijacking
- identical section layouts
- constant animation
- every card having same radius and style
